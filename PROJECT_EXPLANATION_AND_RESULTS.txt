2. IMPLEMENTATIONS & ARCHITECTURES
--------------------------------------------------------------------------------
  1. `src/kmeans_serial.cpp`:
     1-core C++17 Lloyd's K-Means baseline (`results/centroids_serial.txt`) +
     post-convergence UCI HIGGS signal/background cluster analysis across all
     11,000,000 events (`kmeans_cpu_benchmarks.o1565343`).
  2. `src/kmeans_mpi.cpp`:
     Pure MPI distributed-memory 1D row-block decomposition (`MPI_Scatterv` +
     distributed parallel I/O `-io parallel`), comparing 3-call separate
     `MPI_Allreduce` vs. single-call packed `-allreduce packed`.
  3. `src/kmeans_omp.cpp`:
     Hybrid `MPI + OpenMP` (`MPI_THREAD_FUNNELED`, `#pragma omp simd`) comparing
     64-byte cache-padded thread-private accumulators (`-a private`) vs. shared
     `#pragma omp atomic` (`-a atomic`), OpenMP schedules (`static`, `dynamic`,
     `guided`), standalone `-DSTANDALONE_OMP`, and NVIDIA GPU offload `-mp=gpu`.
  4. `src/kmeans_cuda.cu`:
     Hybrid `MPI + CUDA` kernel for Vanda NVIDIA A40 (`__shared__` centroid cache,
     `atomicAddDouble` with `sm_60+` hardware FP64 support, automatic global
     fallback for large K*d).
  5. `src/kmeans_metal_gpu.mm`:
     Hybrid `MPI + Apple Metal` GPU shader (`threadgroup float s_centroids[1024]`,
     zero-copy `MTLResourceStorageModeShared`).
